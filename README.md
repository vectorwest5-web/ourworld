# OUR WORLD — کپسول زمان آفلاین

این پروژه یک وب‌سایت شخصی، رویایی و کاملاً قابل اجرا به صورت آفلاین است.

## ساختار
- `index.html` → صفحه اصلی
- `style.css` → طراحی، انیمیشن‌ها و افکت‌ها
- `script.js` → ورود، نامه‌ها، خاطرات، تایم‌لاین، اتاق مخفی و...
- `assets/music/music.mp3` → آهنگ خودتان
- `local_server.py` → اجرای سایت با Python روی کامپیوتر

## مرحله 1 — نصب Python
Python 3 را روی کامپیوتر نصب کن. برای اطمینان در CMD بزن:
```bash
python --version
```
اگر جواب نداد:
```bash
py --version
```

## مرحله 2 — اجرای آفلاین
داخل پوشه پروژه CMD را باز کن و بزن:
```bash
python local_server.py
```
بعد مرورگر را روی:
`http://127.0.0.1:8000`
باز کن.

## مرحله 3 — شخصی‌سازی
فایل `script.js` را باز کن و ابتدای فایل این‌ها را عوض کن:
- `HER_NAME`
- `YOUR_NAME`
- `LOGIN_PASSWORD`
- `SECRET_PASSWORD`
- `SPECIAL_DATE`

## مرحله 4 — موسیقی
آهنگ خودت را دقیقاً با نام `music.mp3` داخل:
`assets/music/`
بگذار.

## مرحله 5 — GitHub Pages رایگان
1. در GitHub یک Repository جدید بساز.
2. تمام فایل‌های این پروژه را Upload کن.
3. برو به Settings → Pages.
4. در Build and deployment گزینه Deploy from a branch را انتخاب کن.
5. Branch را `main` و پوشه را `/root` انتخاب کن.
6. Save را بزن.
7. بعد از Deploy، GitHub یک آدرس برای سایت می‌دهد.

## نکته مهم درباره رمز
این سایت سمت کاربر (HTML/JS) اجرا می‌شود. بنابراین رمز داخل `script.js` برای امنیت واقعی نیست و کسی که فایل‌ها را ببیند می‌تواند آن را پیدا کند.
برای یک کپسول زمان شخصی و ساده مناسب است، اما برای اطلاعات محرمانه واقعی از این روش استفاده نکن.

## نکته آفلاین
بعد از اینکه پروژه را کامل کردی، کل پوشه را نگه دار. حتی اگر GitHub Pages در دسترس نباشد، با باز کردن پروژه روی کامپیوتر و اجرای `local_server.py` سایتت قابل استفاده است.
